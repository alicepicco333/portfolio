The same openness in performance: the code projected beside the visuals, so the audience can see how every change is made.

Brief
A real-time audiovisual system for a live music event.
Role
Visuals, performing as 5PIC3.
Method
Algorithmic, audio-reactive Hydra patches driven by the music's frequency bands, with the code projected alongside the output.
Outcome
A 23-minute set, recorded in full.
Stack
Hydra · JavaScript

Key decisions

  1. 01

    Project the code alongside the visuals.

    Why
    So the room could watch the patches being typed, changed and broken as the music moved.
    Result
    Nothing about how the visuals are made is hidden: the audience reads the system while it runs.
